# ☕ 커피 봇 — 텔레그램 "커피 시켜" → 스타벅스 앱 자동 주문

안드로이드폰 **한 대 안에서** 돌아갑니다.
Termux에서 봇이 실행되고, ADB로 같은 폰의 스타벅스 앱을 사람 대신 누릅니다.

```
텔레그램 "커피 시켜 라떼"
   → 봇이 스타벅스 앱 실행 → Order → 나만의 메뉴 → 라떼 → 주문하기
   → 가까운 매장(또는 지정 지점) 선택 → 결제 화면
   → 텔레그램으로 스크린샷 + [✅ 결제] [❌ 취소]
   → 결제 누르면 앱으로 돌아가 결제 버튼 탭
```

> ⚠️ **iPhone은 안 됩니다.** iOS는 다른 앱 화면을 대신 누르는 것을 허용하지 않습니다.
> ⚠️ 스타벅스 앱 약관상 자동화가 문제될 수 있습니다. 본인 계정·본인 폰에서만 쓰세요.

---

## 1. 준비물

| 항목 | 설치처 |
|---|---|
| Termux | **F-Droid** 버전 (Play스토어 버전은 업데이트 중단) |
| ADB Keyboard | GitHub `senzhk/ADBKeyBoard` 릴리스 APK. 지점 이름을 **한글로 검색할 때만** 필요 |
| 스타벅스 앱 | 로그인, 결제수단(스타벅스 카드) 등록 완료 상태 |
| 텔레그램 봇 | @BotFather에서 **커피 봇 전용**으로 새로 발급 |

스타벅스 앱의 **나만의 메뉴**에 자주 먹는 메뉴를 옵션까지 저장해 두세요.
봇은 나만의 메뉴에서 이름으로 찾아 주문합니다.

## 2. 설치 (Termux)

```bash
pkg install -y git
git clone https://github.com/won3ho-max/go.git
cd go/coffee_bot
bash setup_termux.sh
nano .env          # TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID 입력
```

채팅 ID는 봇에게 아무 메시지나 보낸 뒤 `https://api.telegram.org/bot<토큰>/getUpdates`에서 `chat.id`를 확인하면 됩니다.

## 3. ADB 연결 (폰이 자기 자신에게 연결)

1. 설정 → 휴대전화 정보 → **빌드번호 7번 탭** → 개발자 옵션 활성화
2. 개발자 옵션 → **무선 디버깅** 켬 (와이파이 연결 필요)
3. 무선 디버깅 → **페어링 코드로 기기 페어링** → 화면 분할로 Termux를 띄우고:
   ```bash
   adb pair localhost:<페어링 포트> <6자리 코드>
   adb connect localhost:<무선 디버깅 화면의 IP 주소·포트의 포트>
   ```
4. **(권장) 와이파이 없이도 쓰려면** 연결된 상태에서 한 번:
   ```bash
   adb tcpip 5555
   adb connect localhost:5555
   ```
   이후에는 LTE에서도 `localhost:5555`로 붙습니다. **폰을 재부팅하면 3~4번을 다시** 해야 합니다.
5. `.env`의 `ADB_SERIAL`을 `adb devices`에 보이는 이름으로 맞춥니다 (보통 `localhost:5555`).

## 4. 실행

```bash
bash start.sh
```

- 설정 → 앱 → Termux → 배터리 → **제한 없음**으로 바꿔야 백그라운드에서 죽지 않습니다.
- 재부팅 후 자동 실행을 원하면 Termux:Boot를 설치하고 `~/.termux/boot/`에 start.sh를 연결하세요. 다만 ADB 연결은 재부팅 때마다 다시 해야 합니다.

## 5. 첫 실행 때 반드시 할 일: 버튼 이름 맞추기

`config.example.json`의 버튼 이름(`Order`, `나만의 메뉴`, `주문하기`, `결제하기` 등)은 **실제 앱을 보지 않고 쓴 추정치**입니다.

1. 텔레그램에 `/status` → 연결·앱 설치 확인
2. 스타벅스 앱을 직접 한 단계씩 넘기면서 화면마다 `/dump`
   → 봇이 화면 속 글자 목록(👆 = 누를 수 있음)과 스크린샷을 보내 줍니다
3. 그 글자에 맞게 `config.json`의 `steps`를 고칩니다
4. **`"confirm_before_pay": true` 상태로** `커피 시켜`를 해 보며 결제 직전까지 가는지 확인합니다
5. 실패하면 봇이 "N단계 실패 + 스크린샷"을 보내 줍니다. 그 단계만 고치면 됩니다

### steps 문법

```json
{"action": "tap", "text": "주문하기", "contains": true, "timeout": 10}
```

| action | 설명 |
|---|---|
| `launch` | 앱 실행 (`restart: true`면 강제 종료 후 새로 실행) |
| `tap` | `text` / `desc`(아이콘 설명) / `id`로 찾아 탭. `scroll: true`면 내려가며 찾음 |
| `wait` | 요소가 뜰 때까지 대기 |
| `type` | 글자 입력 (`{store}`, `{menu}` 변수 사용 가능) |
| `tap_xy` | 좌표 탭 (`x`, `y`를 0~1 비율로 쓰면 해상도와 무관) |
| `sleep` / `back` / `key` | 대기 / 뒤로가기 / 키 입력 |
| `checkpoint` | 여기서 멈추고 텔레그램으로 결제 확인 |

공통 옵션: `optional`(없으면 건너뜀), `if`/`unless`(`store`·`menu`가 있을 때만/없을 때만), `contains`(부분 일치), `regex`, `index`(여러 개 중 몇 번째), `after`(탭 후 대기 초).

## 6. 텔레그램 명령

| 입력 | 동작 |
|---|---|
| `커피 시켜` | 기본 메뉴, 가까운 매장 |
| `커피 시켜 라떼` | 별칭 `라떼` → config의 `menus`에서 실제 이름으로 변환 |
| `커피 시켜 라떼 역삼점` / `@역삼` | 지점 지정 (한글 검색이라 ADB Keyboard 필요) |
| `/stop` | 진행 중 주문 중단 |
| `/dump` `/shot` `/status` `/menus` | 화면 글자 / 스크린샷 / 연결 상태 / 메뉴 별칭 |

## 7. 알려진 한계

- **화면 잠금이 걸려 있으면 동작하지 않습니다.** 같은 폰에서 텔레그램을 쓰는 중이면 이미 풀려 있으니 보통 문제가 없습니다.
- 봇이 누르는 동안 화면을 만지면 흐름이 꼬입니다.
- 스타벅스 앱 업데이트로 버튼 이름이나 배치가 바뀌면 `/dump`로 다시 맞춰야 합니다.
- 결제 화면은 캡처가 막혀 스크린샷이 검게 나올 수 있습니다. 글자 인식(`/dump`)은 그래도 됩니다.
- 결제 때 비밀번호나 생체 인증을 요구하도록 설정돼 있으면 봇이 통과할 수 없습니다.
- `adb tcpip 5555`를 켜 두면 같은 와이파이의 다른 기기도 접속을 **시도**할 수 있습니다(폰에 허용 팝업이 뜸). 모르는 허용 요청은 거절하세요.
- `confirm_before_pay`를 `false`로 끄면 완전 자동이 됩니다. 대신 봇 토큰이 새면 남이 주문할 수 있는 구조가 되니 권장하지 않습니다.
